# Plan — bug fix batch 2 (`docs/bug_fixes/2/2.md`)

Three frontend defects on `/credit-cases`, all in code added earlier today by
`credit_cases_column_filter_sort`. No backend changes.

## 1. Filter dropdown cut off on the left

**Cause.** The dropdown is `absolute right-0` inside the table header cell, and the table lives in a
`overflow-x-auto` wrapper (`page.tsx`). A scroll container clips its descendants, so on the leftmost
sortable column (CUSTOMER) the 16rem panel is sliced off at the wrapper's left border — visible in
`image.png` as "n customer…" / "ee Broomsticks".

**Fix.** Render the panel through `createPortal` into `document.body` and position it `fixed`,
measured from the filter button's `getBoundingClientRect()`. Nothing in the table can clip it, at any
column, at any scroll offset.

- Right-align to the button by default (`left = rect.right - width`), then clamp into the viewport
  with an 8px margin so the leftmost column can't go negative and the rightmost can't overflow.
- Flip above the button when there isn't room below.
- Recompute on `scroll` (capture phase, so the table's own scrolling counts) and on `resize`.
- The existing wrapper `onBlur` containment check stops working once the panel is not a DOM
  descendant, so replace it with document-level `mousedown` + `focusin` listeners that close when the
  event target is outside both the button and the panel.

## 2. Buttons too small, arrow cursor instead of a hand

- **Cursor, app-wide** (confirmed with the user): add
  `button:not(:disabled) { cursor: pointer; }` to `src/app/globals.css`. Tailwind v4's preflight
  dropped the old default, so this affects every button in the app, not just this page.
- **Size**: give the sort and filter buttons a real hit target — `h-6 w-6` / `h-6` centred boxes with
  a larger glyph and icon, up from the current `px-1 text-xs`. Bump the dropdown's option rows and
  Clear button padding a little to match.

## 3. Customer column should link to the credit case

In `page.tsx`, the Customer cell's `<Link href={/customers/${cust.id}}>` becomes
`/credit-cases/${cc.id}`. The customer detail page stays reachable through the Customers nav item in
`AppShell`, so nothing becomes orphaned.
