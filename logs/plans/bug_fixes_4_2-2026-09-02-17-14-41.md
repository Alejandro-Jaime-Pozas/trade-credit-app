# Plan — bug fixes 4/2

Logged 2026-09-02. Prompt: `logs/prompts/bug_fixes_4_2-<same timestamp>.md`.

## Scope

One control: `frontend/src/components/ValueCombobox.tsx`, plus the placeholder the credit case
detail page passes it. No backend, no API, no new endpoint — a custom field value has always
been created by using it.

## Changes

1. **A `+ Create "…"` row at the foot of the list**, copying the customer search on
   `/credit-cases/new` — the pattern the user themselves pointed at when this control was
   specified. Suppressed when the typed text already IS one of the values, compared
   case-insensitively: offering "Create mty norte" beside the existing "MTY Norte" would invite
   the exact duplicate this control exists to prevent.

2. **Revert yesterday's no-match fallback.** 4/1 showed the whole list again when a search
   matched nothing, on the reasoning that an empty list reads as "invalid value". The create row
   answers that concern directly and far better, and keeping both would bury the new row under
   every value that does not match. Matching is now a plain filter.

3. **Open the panel for a field with no recorded values**, as soon as the user types. Previously
   a field with an empty option list rendered a plain text box with no dropdown at all — and the
   empty field is precisely the one where "can I just type one?" needs answering. The caret
   button still only appears when there is something to browse.

4. **A footer line: "Added to this field when you save the case."** Custom fields save with the
   rest of the Details section (bug 4/1, item 4), so without this "Create" reads as a promise
   something was written, and the user leaves the page having lost it.

5. **Placeholder "Pick or type a value"** on custom field boxes, so the affordance is visible
   before the dropdown is ever opened.

The rows the arrow keys walk become one list of tagged entries rather than options plus a bolted-on
special case, so Enter commits whatever is highlighted without the keyboard path caring which kind
of row it is.
