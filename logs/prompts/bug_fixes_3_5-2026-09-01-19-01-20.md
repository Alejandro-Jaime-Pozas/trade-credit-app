2. Editing a credit case's required documents and clicking Done should raise the same

4. Cancel in the save-required-documents prompt issues a PATCH. It should issue nothing.

## Clarification asked for and received

Item 2's "update all" was ambiguous — it could mean other open cases only, the org's default
template as well, or nothing but a confirm step. The user chose **template + other open cases**:
the edited case's document list becomes the organization's new default, and the prompt then
offers to push it onto the other open cases. "Only this case" changes just this case;
"Cancel" writes nothing anywhere.

Item 4's clarification is the governing rule for the whole feature: **Cancel makes no HTTP
request at all.** That is what forced the save flow to be inverted (preview first, write after
the user agrees) rather than kept as save-then-undo.
