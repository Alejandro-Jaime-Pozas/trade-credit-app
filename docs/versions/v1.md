## Implementation



### Signup Workflow

- [x] user: types email, pwd
- [x] backend: new user created
- [x] user: clicks log in, types credentials
- [x] backend: logs user in
- [x] backend: sets the organization to the user's email for now (implement later or allow user to change org name)



### Credit Case Workflow

- [x] user clicks on create new credit case
- [x] user creates new customer profile to link to new credit case (or links to existing customer)
  - Customer model fields in form
    - filled out manually by user in v1
      - can (later) be extracted from docs like constancia CSF
    - key fields
      - rfc
      - legal name
      - name
      - address (multiple address fields in Customer model)
- [x] show user new credit case fields (some populated) after they create customer profile (not implemented; user must manually create the credit case after creating a customer)
- [x] credit case default required files specified in @backend/core/constants.py as CREDIT_CASE_FILE_TYPE_NAMES_REQUIRED
  - [x] user can input/update fields for created credit case
    - requested_amount
    - currency
    - requested_term_days
    - assigned_to
- [x] user uploads files (UploadDocument model) to credit case detail view (can bulk load, or single load)
  - this uploads the file to UploadDocument @backend/storage/models.py, linking the file to customer and credit case
    - file has no link yet to a specific file type name required
- [x] backend extracts the file contents to match the file type with a required file type if exists, else marks as unknown file type (this requires the openai/chatgpt integration in @backend/integrations/openai/services/gpt.py to extract the correct file type name)
- [x] user can then change credit case status as it progresses (missing data, pending credit review, pending authorization), upload more files, change credit case model data (status choices implemented, though current values differ from the names listed here: `missing_documents`, `pending_ai_verdict`, `buro_de_credito_rejected`, `pending_final_verdict`, `complete`)
