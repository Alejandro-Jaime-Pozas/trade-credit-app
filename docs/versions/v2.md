### Nice-to-haves (not priority)

- auto-save on customer/credit case edit forms, instead of requiring explicit "Save" clicks
  - event-driven, not polling: debounce onChange (~800ms-1s of inactivity), then PATCH just the changed field(s)
  - optimistic UI with a "Saving.../Saved" indicator; retry with backoff on failure
  - also flush the save on blur and on navigation away (e.g. `beforeunload` / route change, via `navigator.sendBeacon` so it survives tab close)
  - periodic safety-net flush (e.g. every 30s) in case the user never stops typing
  - not needed: OT/CRDT-style collaborative conflict resolution (Google Docs/Figma-style) — this app isn't multi-user-per-record realtime, so last-write-wins per field is sufficient
